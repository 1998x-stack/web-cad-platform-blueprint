# 00｜产品章程：Web CAD × 模型商店 × AI Agent

## 0.1 North Star

让用户从“发现一个可复用模型”到“修改其精确尺寸、获得可验证的工程文件”能够完成连续工作流。长期允许 AI 使用同样的工具操作模型，保留人类可审查的设计历史。

## 0.2 人群与 Jobs To Be Done

1. **机械/产品设计师**：希望用浏览器修改参数化零件，不装桌面 CAD；优先重视精度、编辑历史、STEP。
2. **3D 打印创作者**：需要按尺寸调整模型并下载 STL/3MF；优先重视水密、法向、厚度、单位。
3. **家具/室内设计者**：需要桌椅/柜体组件、尺寸配置和场景预览；优先重视资产复用与装配。
4. **开发者与 AI Agent**：需要通过明确的协议查询、生成、检验和导出模型，而不是模拟鼠标操作。
5. **模型贡献者**：上传资产、描述授权、管理发布版本和分类信息。

## 0.3 四个产品域与最小闭环

- **模型商店**：浏览 → 筛选 → 预览 → 查看格式与许可 → 复制模型 ID/下载 → 在编辑器打开。
- **CAD Studio**：建立文档 → 绘制受约束草图 → 添加 3D 特征 → 检查精确几何 → 保存 → 导出。
- **模型交换**：选择源与目标格式 → 验证能力与丢失信息 → 转换任务 → 验证产物 → 获取链接。
- **Agent/MCP**：读取能力 → 读取授权范围 → 查询文档 → 提交离线预览 → 检查证据 → 显式提交 → 导出产物。

## 0.4 原则与不变式

- Canonical Document 是设计事实来源；渲染 Mesh 仅为派生视图。
- 所有有状态更改必须经过同一 `CommandService`；任何 AI 代码不能绕过授权直接改库。
- 每次提交必须携带预期修订号（optimistic concurrency control）；冲突返回可恢复错误。
- 每个几何特征都有稳定逻辑 ID；显示和真实拓扑 ID 分离。
- 发布资产为不可变 Release，修改必须创建新 Release。
- 格式转换不得冒充“无损”：STL/GLB 不包含原生特征树；STEP 一般也不会恢复供应商私有历史。
- 任何生成的工程文件都必须通过格式和几何核验；失败以错误状态返回，不自动声称成功。

## 0.5 首期范围与非目标

**P0–P2 范围**：单用户、本地优先、mm 单位、基础实体与草图、尺寸约束、设计历史、GLB 预览、STEP/STL 导出、简单模型索引。

**刻意排除**：全功能 DWG 编修、复杂曲面自由造型、实时多人冲突合并、制造认证、真实 CAM 刀路、有限元仿真、精确 GD&T 认证、复杂装配运动求解、移动端专业绘图。

## 0.6 产品指标（假设目标，待用户访谈验证）

| 指标 | 初期试验目标 | 采集方式 |
| --- | --- | --- |
| 首次建立可编辑零件成功率 | ≥80%（内测任务） | 任务完成事件 + 客户反馈 |
| 保存后重开无损率 | 100%（测试语料） | 自动化同值比较 |
| 有效几何导出成功率 | ≥95%（受支持测试样本） | kernel + 文件回读 |
| 元数据查询 P95 | <300ms（10k 索引，本地压力） | API 基准测试 |
| 静态 3D 查看交互流畅性 | 目标 30–60FPS（指定设备和样本） | 性能采样 |
| AI 未授权提交数 | 0 | 安全测试 + 审计 |

这些是**规划目标**，不是目前产品已有指标，性能必须说明测试机型和数据集。

## 0.7 术语

- **B-Rep**：边界表示法，精确曲面、曲线和拓扑关系。
- **Mesh**：三角网格，常用于 GPU 显示和网格打印。
- **Sketch Solver**：二维几何约束求解器。
- **Feature DAG**：参数化建模特征依赖有向无环图。
- **Revision**：文档提交后的逻辑修订号，不等于 Git commit。
- **Detached Preview**：不修改主文档的建模预览与验证。
- **Headless CAD**：服务端无浏览器界面的 CAD 运算；与可见浏览器授权路径应独立授权。
